# История изменений WindowsProfileMigration

Автор проекта: Arhivater.

## v1.10.1

### Запуск и диагностика

- `Start.cmd` выбирает 64-разрядный PowerShell и возвращает точный код запуска, включая отмену UAC.
- Загрузчик разрешает путь к корню диска и UNC, однократно запрашивает права и запускает основной скрипт из исходного комплекта.
- Проверка платформы отличает клиентскую Windows 10/11 от Windows Server. Ввод с завершившегося потока обрабатывается как отмена.
- USMT ищется в комплекте и Windows ADK. Загрузка подписанного установщика ограничена по времени. Загрузка и установка подтверждаются отдельно.
- Этапы и реальное время записываются в один итоговый TXT. Для длительных операций проценты показываются, когда известен объём работы. Отчёт содержит фактические коды USMT, ADK и reg.exe.

### Экспорт, архив и импорт

- Повторная проверка SID, каталога и состояния загруженности перед ScanState и при сверке результата. Список файлов проверяется в пределах выбранного профиля.
- Метаданные ZIP и архивов-папок читаются с одинаковым ограничением. Распаковка использует тот же дескриптор, что и проверка. Проверяются пути Windows, перенаправления, размер и структура записей.
- Проверяются строки манифестов, размеры и SHA-256, правила USMT и доказательство области профиля. Готовый ZIP публикуется после проверки хеша без замены существующего файла.
- Потоки манифеста профиля, манифеста Extras и списка USMT закрываются при успехе и отказе. Чтение списка сохраняет поддержку файлов с BOM.
- Исторические схемы 1–6 можно проверить через меню. LoadState запускается для схемы 7 после проверки подготовленной копии.
- Назначение выбирается через цифровое меню. Перед записью повторно проверяются SID, локальная или доменная учётная запись и наличие профиля. Одновременный импорт и восстановление блокируются.
- Состояние импорта обновляется атомарно. Неопределённый результат LoadState требует ручной проверки назначения. Локальный пароль не передаётся через WinRM и не сохраняется в отчёте.
- Журналы, кеш, резервные копии и исходные ZIP прямого переноса помещаются в закрытый рабочий каталог. Старые журналы доступны для просмотра. Для отката значков проверяется SHA-256 резерва.
- Ограничено ожидание отменённых USMT и Robocopy. Исходные архивы и профили сохраняются.

### Дополнительные настройки

- Копируются только предусмотренные файлы браузеров. Их обработка независима, заблокированный браузер отражается в собственном результате.
- При восстановлении файлов проверяется хеш используемой копии. Для заменяемых настроек браузеров, Проводника и 1С сохраняются предыдущие данные.
- Сетевые буквы проверяются по одной, с учётом UNC и занятых томов. Реестр пользователя проверяется по фактическому SID.
- Параметры рабочего стола проверяются до записи. При частичном сбое восстанавливаются прежние значения. Визуальная проверка выполняется после входа.

### Прямой перенос

- ZIP передаётся блоками по настроенному WinRM с подтверждением записанных байтов. При обрыве повторно проверяется получатель и хеш сохранённого префикса. Перед запуском импорта сверяется полный SHA-256.
- Получатель хранит файлы в защищённом рабочем каталоге, а повторный запуск проверяет запись импорта для конкретного архива и назначения.
- Проверяются версия Windows, архитектура, место, учётная запись, политика PowerShell и наличие полного комплекта USMT. Источник получает отдельный отчёт целевого ПК.

### Испытания

- Добавлены синтетические тесты загрузчика, меню, архивов, импорта, Extras, WinRM-передачи и восстановления.
- Финальный автоматический прогон прошёл 73 проверки на Linux и 75 на Windows Server 2022 с Windows PowerShell 5.1. [Журнал Windows](https://github.com/Arhivater/WindowsProfileMigration/actions/runs/44786728590)
- Аудит и результаты проверок описаны в `AUDIT_REPORT.md` и `TEST_CHECKLIST.md`. Порядок испытаний Windows 10/11 описан в `TESTING_GUIDE.md`.

# WindowsProfileMigration

Переносите профиль пользователя на новый ПК с Windows 10 или 11. На исходном компьютере выберите учётную запись. На целевом — проверьте архив и восстановите файлы и настройки через русскоязычное меню. Команды Microsoft USMT программа соберёт сама.

## Первый перенос

| Где | Что сделать |
| --- | --- |
| **На исходном ПК** | Распакуйте комплект. Выйдите из переносимого профиля, войдите под другим администратором и запустите `Start.cmd`. Выберите **1 · Экспорт**, укажите пользователя и папку для ZIP. |
| **Между компьютерами** | Скопируйте ZIP на флешку или в доступную сетевую папку. Для прямого переноса по WinRM выберите **6** на целевом ПК, затем **5** на исходном. |
| **На целевом ПК** | Откройте `Start.cmd` из распакованного комплекта. Выберите **3 · Проверка архива**, затем **2 · Импорт**. После завершения войдите под целевым пользователем и проверьте документы и рабочий стол. |

Понадобятся права администратора и 64-разрядный Windows PowerShell 5.1. Если USMT отсутствует, программа предложит загрузить и установить компонент Windows ADK.

## Если перенос прервался

- **Оборвалась связь во время отправки ZIP?** Пункт **7** позволяет продолжить передачу. Перед импортом программа сверяет SHA-256 архива на получателе.
- **Компьютер перезагрузился во время импорта?** Откройте пункт **4** на целевом ПК. Журнал покажет, успел ли запуститься LoadState, чтобы вы могли проверить состояние профиля перед повторной попыткой.

## Что нового в v1.11.0

В релизной ветке можно защитить архив паролем, добавить отдельную копию локальных «Документов» и «Загрузок» и восстановить ярлыки рабочего стола. Ярлык на сетевой файл, сайт или RDP-подключение сохраняется вместе с адресом, даже когда ресурс недоступен.

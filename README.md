# WindowsProfileMigration v1.11.0

Перенос одного пользовательского профиля между компьютерами с Windows 10 и Windows 11 с помощью Microsoft USMT. Можно перенести архив вручную или отправить его на другой ПК через WinRM.

**[Скачать комплект v1.11.0 для Windows](https://raw.githubusercontent.com/Arhivater/WindowsProfileMigration/release/v1.11.0/dist/WindowsProfileMigration_v1.11.0_Arhivater.zip)**

1. Распакуйте комплект. На исходном ПК выйдите из переносимой учётной записи и запустите `start.cmd` под другим администратором.
2. Выберите **1** для экспорта. Укажите, включать ли отдельную копию локальных файлов из «Документов» и «Загрузок», и нужна ли защита паролем. Ярлыки рабочего стола программа сохраняет при обоих вариантах.
3. На целевом ПК запустите `start.cmd`. Выберите **3**, чтобы проверить архив, затем **2**, чтобы импортировать его. После переноса войдите под целевым пользователем.

# WindowsProfileMigration v1.11

Перенос одного профиля между компьютерами с Windows 10 и 11. Эта сборка добавляет архив с паролем, отдельную копию локальных документов и загрузок, а также автоматический перенос ярлыков рабочего стола.

## Что взять на новый ПК

| Что переносите | Как это устроено |
| --- | --- |
| **Профиль** | Microsoft USMT собирает данные выбранной учётной записи. В меню можно выбрать обычный ZIP или защитить его паролем в формате OpenPGP (`.wpm.pgp`). |
| **Документы и загрузки** | При экспорте можно добавить отдельную копию локальных файлов и подпапок. Если при восстановлении имя занято файлом с другим содержимым, копия получит отдельное имя. |
| **Ярлыки рабочего стола** | Программа сохраняет файлы `.lnk`, `.url`, `.website` и `.rdp` автоматически. Для копирования ярлыка доступ к его цели не требуется. |

## Как запустить

1. **Исходный ПК.** Распакуйте комплект, выйдите из переносимого профиля и запустите `start.cmd` под другим администратором. В пункте **1** выберите профиль, состав архива, защиту и папку сохранения.
2. **Передача.** Скопируйте архив на новый ПК. Для прямого переноса через WinRM выберите **6** на целевом ПК и **5** на исходном.
3. **Целевой ПК.** Выберите **3** для проверки архива, затем **2** для импорта. Войдите под восстановленной учётной записью и откройте свои файлы. Путь к итоговому отчёту программа покажет на экране.

## Если произошёл сбой

Откройте итоговый TXT по пути на экране. В нём есть версия программы и Windows, время этапов, итог, число обработанных объектов и коды ошибок. Для сообщения о сбое укажите компьютер, номер пункта меню и последние записи перед ошибкой. Перед отправкой проверьте имена пользователей, компьютеров и пути в отчёте.

Индикатор операции показывает долю завершённых шагов. Внутренние индикаторы считают байты, файлы или группы, когда известен их объём. Для ожидания ответа Windows или WinRM показывается текущее действие.

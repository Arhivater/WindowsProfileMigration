# WindowsProfileMigration

Перенос выбранного профиля между компьютерами с Windows 10 и Windows 11. Программа сохраняет профиль в ZIP с помощью Microsoft USMT, проверяет контрольные суммы и восстанавливает данные на целевом ПК. Архив можно перенести вручную или передать по сети через WinRM.

**[Скачать комплект v1.10.1 для Windows (.zip)](https://github.com/Arhivater/WindowsProfileMigration/releases/download/v1.10.1/WindowsProfileMigration_v1.10.1_Arhivater.zip)** · [Что изменилось в этой версии](https://github.com/Arhivater/WindowsProfileMigration/releases/tag/v1.10.1)

## Первый перенос

1. Распакуйте комплект на обоих ПК. На исходном ПК выйдите из переносимой учётной записи, войдите под другим администратором и запустите `Start.cmd`. Подтвердите запрос прав, если он появится. Если USMT отсутствует, программа предложит загрузить и установить компонент Windows ADK.
2. Для экспорта выберите **1**, укажите профиль и папку для сохранения. Скопируйте полученный ZIP профиля на целевой ПК.
3. На целевом ПК запустите `Start.cmd`. Выберите **3** для проверки ZIP профиля, затем **2** для импорта. Проверьте учётную запись назначения перед подтверждением.
4. После импорта войдите под целевым пользователем и проверьте документы, рабочий стол и настройки приложений. Путь к итоговому отчёту программа покажет на экране.

Для прямого переноса по сети выберите **6** на целевом ПК, затем **5** на исходном. Порядок возобновления после обрыва приведён в инструкции. [Инструкция пользователя](README.txt)

## Статус испытаний

Версия v1.10.1 готова к испытаниям на синтетических профилях. На Windows 11 ARM64 и Windows Server 2022 прошли все 76 автоматических проверок, на Linux прошли 73 из 73. На Windows 11 также проверен запуск через `Start.cmd` и выход из меню. Сквозной перенос на Windows 10/11, вход под восстановленным пользователем и испытания между доменами требуют отдельного стенда.

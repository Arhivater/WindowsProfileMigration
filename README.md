# WindowsProfileMigration

WindowsProfileMigration переносит файлы и настройки одного пользователя между компьютерами с Windows 10 и 11. На старом ПК программа сохраняет профиль в архив, на новом - проверяет архив и восстанавливает данные для выбранной учётной записи. Для переноса используется Microsoft USMT.

## Возможности

- **Перенос профиля.** Архив содержит файлы и настройки выбранного пользователя. Можно отдельно добавить «Документы» и «Загрузки». Ярлыки рабочего стола сохраняются автоматически.
- **Защита архива.** Выберите обычный ZIP или архив с паролем. Перед импортом можно проверить целостность.
- **Работа по сети.** Запускайте комплект с локального диска, из общей папки или с подключённого сетевого диска. Архив можно передать через общую папку. Для автоматического переноса между ПК есть отдельный режим WinRM.
- **Отчёт и повтор.** Программа показывает ход операции и сохраняет TXT-отчёт. Если часть личных файлов осталась невосстановленной, их можно повторно скопировать из проверенного архива.

## Первый перенос

1. **Подготовка.** Скачайте и распакуйте комплект, запустите `start.cmd` и подтвердите запрос Windows на права администратора. Если USMT отсутствует, программа предложит установить его.
2. **Старый ПК.** Выйдите из переносимой учётной записи и войдите под другим администратором. Запустите программу и выберите **1 · Экспорт**. Запишите путь к архиву.
3. **Новый ПК.** Откройте архив из папки, доступной этому компьютеру. В программе выберите **3 · Проверить архив**, затем **2 · Импорт**. После импорта войдите под перенесённым пользователем и проверьте файлы.

Для запуска из общей папки можно открыть её в Проводнике по адресу вида `\\SERVER\Share\WPM`. Чтобы сохранить архив в сети, запустите комплект оттуда и выберите папку `Backups` рядом с программой. Учётной записи администратора понадобится доступ к файлам комплекта, а для сохранения архива - право записи в `Backups`.

Установленные приложения и пароли от них требуют отдельной подготовки. Импорт выполняется для учётной записи без существующего профиля. Перенос с Windows 11 на Windows 10 запрещён.

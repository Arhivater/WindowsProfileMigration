WindowsProfileMigration v1.11.0
Перенос профиля между ПК с Windows 10 и 11
Автор: Arhivater

НА ИСХОДНОМ ПК

1. Распакуйте комплект. Выйдите из переносимой учётной записи,
   войдите под другим администратором и запустите start.cmd.
   Подтвердите запрос прав. Если нужна программа переноса Microsoft
   USMT, меню предложит загрузить и установить её.
2. Выберите 1 (экспорт), затем нужный профиль. По умолчанию
   архив попадёт в папку Backups рядом со start.cmd.
3. Чтобы положить в архив отдельную копию «Документов» и «Загрузок»,
   выберите этот вариант в меню. В копию входят локальные файлы
   и подпапки. Ярлыки рабочего стола сохраняются автоматически,
   включая ссылки на сетевые файлы, сайты и подключения RDP.
4. В меню защиты выберите обычный ZIP или введите пароль дважды.
   Сохраните пароль отдельно, он понадобится для открытия архива.
   Выберите папку для сохранения, подтвердите экспорт и скопируйте архив
   на целевой ПК.

НА ЦЕЛЕВОМ ПК

1. Распакуйте комплект и запустите start.cmd. Выберите 3 (проверка),
   укажите архив. Для файла .wpm.pgp введите пароль от архива.
2. Выберите 2 (импорт), укажите архив, проверьте имя учётной записи
   назначения и подтвердите перенос. Если создаётся локальная учётная
   запись, сохраните пароль, показанный для входа в Windows.
3. Войдите под перенесённым пользователем. Откройте свои документы
   и проверьте ярлыки на рабочем столе. Для сетевых ярлыков нужен
   доступ к прежнему ресурсу.

ПО СЕТИ

На целевом ПК выберите 6 (подготовка к приёму). На исходном ПК
выберите 5 (прямой перенос). После обрыва выберите 7 и укажите
сохранённый архив. Для защищённого архива снова введите пароль.
Если импорт уже начался, проверьте его состояние на целевом ПК
через пункт 4.

Путь к отчёту появляется на экране. Обычно это папка Reports рядом
со start.cmd. В главном меню 0 закрывает программу.

WindowsProfileMigration v1.10.1
Автор: Arhivater

ПОДГОТОВКА

1. Распакуйте комплект на Windows 10/11. Запустите Start.cmd.
2. Подтвердите запрос администратора. Для сетевой папки у администратора
   должен быть доступ к ней по UNC.
3. Если USMT отсутствует, программа предложит скачать и установить
   компонент Windows ADK. Загрузка и установка подтверждаются отдельно.
4. В меню 0 возвращает назад, в главном меню закрывает программу.
   В подтверждениях 1 продолжает действие, 0 или 2 отменяет его.
   Во время USMT, упаковки, распаковки или копирования можно нажать
   0 без Enter и подтвердить остановку цифрой 1.

ЭКСПОРТ

1. Выйдите из переносимой учётной записи и войдите под администратором.
2. В Start.cmd выберите 1, затем профиль и папку для сохранения.
3. Подтвердите экспорт. Готовый ZIP появится в выбранной папке.
   Папка по умолчанию - Backups рядом со Start.cmd.

ПРОВЕРКА И ИМПОРТ

1. На целевом ПК запустите Start.cmd. Чтобы проверить ZIP или архив-папку,
   выберите 3 и укажите архив.
2. Для импорта выберите 2, укажите архив и подтвердите назначение.
   Если программа создаст локального пользователя, сохраните пароль с экрана.
3. После импорта войдите под целевым пользователем и проверьте документы,
   рабочий стол, Проводник, браузеры, сетевые диски и список баз 1С.

ПРЯМОЙ ПЕРЕНОС ПО СЕТИ

1. На целевом ПК выберите 6 и подтвердите подготовку WinRM. Для HTTPS
   нужен действующий сертификат WinRM. При работе по IP или между доменами
   используйте сетевые настройки, разрешённые администратором.
2. На исходном ПК выйдите из переносимой учётной записи. Запустите
   Start.cmd под администратором и выберите 5. Укажите профиль, имя,
   FQDN или IP целевого ПК, транспорт и учётную запись назначения.
3. Подтвердите перенос. Программа проверит полученный ZIP по SHA-256
   и запустит импорт. Для нового локального пользователя на получателе
   администратор целевого ПК задаёт пароль перед первым входом.
4. При обрыве связи выберите 7 и укажите сохранённый ZIP и прежнее
   назначение. Если импорт мог начаться, проверьте состояние операции
   на целевом ПК через пункт 4 до повторной попытки.

СОСТОЯНИЕ ОПЕРАЦИЙ И ОТЧЁТЫ

Пункт 4 показывает незавершённые операции и доступные варианты очистки
и восстановления настроек. Старые журналы открываются для просмотра.
По окончании программа выводит путь к отчёту.

- Отчёты: Reports рядом со Start.cmd или путь, показанный на экране.
- ZIP прямого переноса: %ProgramData%\WindowsProfileMigration-Work\DirectTransfers.
- Отчёт и ZIP назначения: %ProgramData%\WindowsProfileMigration-RemoteDeploy
  на целевом ПК. Путь к архиву виден в итоговом отчёте источника.

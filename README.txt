КРАТКАЯ ИНСТРУКЦИЯ

1. ПОДГОТОВКА
1. Распакуйте комплект в любую папку на компьютере, флешке или сетевом диске.
2. Запустите Start.cmd и подтвердите права администратора.
3. Если программа предложит установить USMT, выберите установку цифрой.
4. В меню используйте 0 для отмены или возврата назад. В главном меню 0 закрывает программу.
5. В подтверждениях 1 - продолжить; 0 или 2 - отменить.
6. Во время USMT, упаковки, распаковки или копирования нажмите 0 без Enter; затем 1 - остановить, 0 или 2 - продолжить работу.

2. ЭКСПОРТ ПРОФИЛЯ
1. Выйдите из учётной записи пользователя, профиль которого переносите.
2. Войдите под другой учётной записью с правами администратора.
3. Запустите Start.cmd и выберите 1 - Экспорт.
4. Выберите нужного пользователя по номеру.
5. Выберите 1 для сохранения в Backups рядом со Start.cmd либо другой диск цифрой.
6. Подтвердите экспорт и дождитесь итогового сообщения. В Backups появится один ZIP-файл.

3. ИМПОРТ ПРОФИЛЯ
1. На целевом устройстве откройте тот же комплект с сохранённым архивом.
2. Запустите Start.cmd от администратора.
3. Выберите 2 - Импорт.
4. Выберите ZIP по номеру или пункт выбора другой папки. Распаковка выполняется автоматически.
5. Подтвердите восстановление. Если создан локальный пользователь, сохраните показанный пароль.
6. После завершения войдите в восстановленную учётную запись и проверьте данные.

4. ПРОВЕРКА АРХИВА
1. Запустите Start.cmd.
2. Выберите 3 - Проверить архив.
3. Выберите ZIP или архив-папку по номеру и дождитесь результата.

5. СОСТОЯНИЕ ОПЕРАЦИЙ
1. Запустите Start.cmd.
2. Выберите 4 - Состояние операций, очистка и восстановление настроек.
3. Выберите нужную операцию и дальнейшее действие цифрой.

6. ПРЯМОЙ ПЕРЕНОС С ПК НА ПК ПО СЕТИ
1. Соедините оба компьютера с одной доступной сетью. Для работы по имени проверьте DNS; для другого домена можно использовать FQDN или IP.
2. На целевом компьютере запустите Start.cmd от администратора и выберите 6 - Подготовить этот ПК к приёму. Подтвердите цифрой 1.
3. Для домашней сети выберите в Windows профиль сети «Частная». Для корпоративной сети используйте настройки удалённого администрирования, разрешённые ИТ-отделом.
4. На исходном компьютере завершите сеанс переносимого пользователя и войдите под другим администратором.
5. Запустите Start.cmd, выберите 5 - Прямой перенос по сети и выберите профиль пользователя цифрой.
6. Введите имя целевого ПК, FQDN (например, pc.example.local) либо его IP-адрес.
7. Выберите цифрой транспорт: 1 - WinRM HTTP, 2 - WinRM HTTPS. Для HTTPS предварительно настройте действующий сертификат WinRM на целевом ПК.
8. Выберите цифрой администратора назначения: 1 - текущая учётная запись; 2 - другие учётные данные. При выборе 2 введите DOMAIN\admin или COMPUTER\admin и пароль.
9. Выберите цифрой учётную запись назначения: исходную, локальную на новом ПК или DOMAIN\user. Для разных доменов укажите существующего пользователя целевого домена.
10. Проверьте источник и назначение на экране и подтвердите цифрой 1.
11. Дождитесь создания ZIP, его передачи, проверки SHA-256 и автоматического развёртывания профиля на целевом ПК.
12. Войдите под восстановленным пользователем на целевом ПК и проверьте документы, Проводник, сетевые диски, список баз 1С и браузеры.

7. ПОДКЛЮЧЕНИЕ МЕЖДУ РАЗНЫМИ ДОМЕНАМИ И ПО IP
1. На обоих ПК используйте разрешённые администраторами сетевые правила WinRM.
2. При подключении по IP укажите учётные данные администратора целевого ПК (пункт 2 в выборе входа).
3. Для соединений без Kerberos настройте на целевом ПК WinRM HTTPS с сертификатом либо внесите точное имя/IP целевого ПК в TrustedHosts исходного ПК по политике вашей организации.
4. После подготовки повторите прямой перенос через пункт 5.

8. ПРОДОЛЖЕНИЕ ПОСЛЕ СБОЯ СЕТИ ИЛИ ОТКЛЮЧЕНИЯ ПК
1. Дождитесь включения обоих компьютеров и восстановления сети.
2. На исходном ПК откройте Start.cmd и выберите 7 - Продолжить прерванный сетевой перенос.
3. Выберите сохранённый ZIP по номеру.
4. Укажите целевой компьютер и пользователя назначения, как при прямом переносе.
5. Подтвердите цифрой 1. Программа проверит наличие уже переданного ZIP и продолжит сетевое развёртывание.
6. Если на целевом ПК уже создан профиль после прерванного LoadState, откройте пункт 4 и проверьте состояние операции до повторного применения архива.

РЕЗУЛЬТАТЫ
Архивы ZIP по умолчанию: Backups рядом со Start.cmd.
Итог каждой операции: Reports\Итог_работы_*.txt рядом со Start.cmd.
Прямой перенос: исходный ZIP хранится в C:\ProgramData\WindowsProfileMigration\DirectTransfers; на получателе - в C:\ProgramData\WindowsProfileMigration\RemoteDeploy\WPM_*\Backups.
На целевом ПК сохраняется собственный итоговый TXT; при успешном прямом переносе его содержимое включается в итоговый TXT источника.

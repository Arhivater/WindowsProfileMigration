# Точка продолжения WindowsProfileMigration v1.10.1

Репозиторий `Arhivater/WindowsProfileMigration`. Ветка испытаний `release/v1.10.1`. База v1.10.0: `0e6f900`.

## Состояние сборки

- Исправления экспорта, импорта, дополнительных настроек, возобновления WinRM и защиты рабочего каталога собраны в одной ветке. Аудит содержит 54 дефекта и сценария отказа с исправлениями.
- Код в `5543174` прошёл 73 из 73 синтетических тестов на Linux и 75 из 75 на Windows Server 2022 с Windows PowerShell 5.1. После этой проверки в ветке уточнены результаты и документация. [Итоговый прогон Windows](https://github.com/Arhivater/WindowsProfileMigration/actions/runs/44786728590)
- PSScriptAnalyzer 1.25.0 сообщил 0 замечаний по синтаксису и командлетам 5.1. Пять предупреждений по типам объяснены в `TEST_CHECKLIST.md`.
- Тестовый пакет, аудит, чек-лист, список изменений и инструкция относятся к тегу v1.10.1. [Тестовый релиз](https://github.com/Arhivater/WindowsProfileMigration/releases/tag/v1.10.1)

## Следующие испытания

1. На чистых ВМ Windows 10 и Windows 11 пройти W01–W11 из `TESTING_GUIDE.md`. Приоритет у экспорта одного выгруженного профиля, проверки ZIP, первого импорта в пустое назначение и безопасного повторного запуска после прерывания LoadState.
2. На парах ВМ проверить W12–W22. Сверить данные приложений после входа. На стенде проверить WinRM по имени и IP, обрыв передачи большого ZIP, повторное подключение, блокировку повторного импорта и доступ стандартной учётной записи к закрытому рабочему каталогу.
3. Для каждого фактического прогона сохранить итоговый TXT, SHA-256 архива и результаты сравнения синтетических файлов. Регистрировать по ID сценария и сборкам ОС. Внести результаты в `TEST_CHECKLIST.md`.
4. При выявленном сбое воспроизвести его на синтетических данных, добавить регрессионный тест и проверить новую сборку. После прохождения критических сценариев пересмотреть статус готовности.

Сквозная миграция USMT, UAC, Active Directory, WinRM и пользовательская приёмка на Windows 10/11 ожидают стенда. Результаты Windows Server относятся к синтетическим тестам.

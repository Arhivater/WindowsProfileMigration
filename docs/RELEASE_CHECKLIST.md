### Воспроизведённые дефекты

- [ ] **Отправитель не видит часть пропущенных данных.** Когда контрольные файлы совпадают, но отсутствует папка AppData/Roaming или файл базовой выборки, получатель пишет предупреждение, а исходный ПК показывает техническое завершение. [Формирование сетевого итога](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Import.ps1#L495-L503)
- [ ] **Пустой контрольный список не отражается у отправителя.** Получатель сообщает, что полноту подтвердить нельзя, но отправитель получает код успешного завершения. [Отчёт получателя](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Import.ps1#L419-L435)
- [ ] **Импорт может завысить требование к месту.** Дополнительная копия того же файла входит и в объём профиля, и в объём Extras. Импорт отказывает до LoadState, хотя при восстановлении идентичный файл не пришлось бы записывать. [Расчёт места](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Import.ps1#L379-L384)
- [x] **Успешный повтор сохраняет предыдущий сбой основного импорта.** При повторной проверке отдельная запись показала успех копирования, а незавершённый импорт сохранил прежний статус и сообщение об ошибке сверки. [Обновление исходной записи](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Recovery.ps1#L510-L514)
- [ ] **Очистка может принять чужой процесс за свой.** Если запуск LoadState завершился ошибкой до записи PID, программа ищет LoadState по имени. Другой процесс с таким именем временно блокирует очистку. [Запись перед запуском](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Usmt.ps1#L192-L205) · [Проверка по имени](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Recovery.ps1#L211-L223)

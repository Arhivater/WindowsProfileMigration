### Дефекты и исправления по результатам тестов

- [x] **Отправитель видит пропуски из базовой проверки.** При отсутствующей папке AppData/Roaming или файле базовой выборки исходный ПК показывает частичный перенос, даже если SHA-256 остальных файлов совпали. [Формирование сетевого итога](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Import.ps1#L495-L503)
- [x] **Пустой контрольный список отражается у отправителя.** При пустом реестре исходный ПК пишет «Полнота переноса не подтверждена». При одновременном обнаружении пропусков показывает частичный перенос и обе причины. [Отчёт получателя](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Import.ps1#L419-L435)
- [x] **Импорт допускает файлы, уже учтённые в размере профиля.** Место для профиля обязательно. Объём возможных дополнительных копий учитывается в предупреждении, а место в фактической папке проверяется перед записью нового файла. [Расчёт места](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Import.ps1#L379-L384)
- [x] **Успешный повтор сохраняет предыдущий сбой основного импорта.** При повторной проверке отдельная запись показала успех копирования, а незавершённый импорт сохранил прежний статус и сообщение об ошибке сверки. [Обновление исходной записи](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Recovery.ps1#L510-L514)
- [x] **При отсутствующем LoadState очистка не ждёт чужой процесс.** Проверка наличия файла выполняется до записи о запуске. При сбое в момент запуска остаётся проверка по имени, пока программа не успела записать PID. [Запись перед запуском](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Usmt.ps1#L192-L205) · [Проверка по имени](https://github.com/Arhivater/WindowsProfileMigration/blob/812988c/Program/Recovery.ps1#L211-L223)
